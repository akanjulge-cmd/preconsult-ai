# MediKiosk / PreConsult AI Hackathon Step-by-Step Plan

## Core Value Proposition
"Voice when you can speak. Touch when you can't. Show where it hurts. Scan what you already have. We prepare the doctor — not replace the doctor."

## 10-Step Patient Journey
1. Identify: ID, preferred language, consent.
2. Show the problem: Interactive body symptom map (Front/Back).
3. Describe symptoms: Voice, touch, audio-guided interaction.
4. Adaptive history: Complaint-specific SOCRATES questions (3–5 flows).
5. AYUSH assessment (optional toggle): Dashavidha Pariksha + Ahara-Vihara parameters.
6. Scan records: Prescriptions, lab reports, discharge summaries via OCR.
7. Safety check: Red-flag detection and priority triage alert.
8. Summarize: Structured clinical history.
9. Doctor review: 60-second brief with Edit, Verify, Confirm workflow.
10. Integrate: FHIR-compatible / mock HIS-ABDM export.

## 5-Minute Hackathon Demo Script
- 0:00–0:30 Problem: Consultation time & documentation bottleneck.
- 0:30–1:00 Solution: PreConsult AI as structured pre-intake layer.
- 1:00–2:00 Patient: Language -> consent -> body map -> visual symptom -> adaptive questions (<4 taps touch demo).
- 2:00–2:30 Documents: Scan prescription/report -> extracted medications & abnormal labs.
- 2:30–3:00 Safety: Trigger red-flag scenario -> urgent priority triage banner.
- 3:00–4:00 Doctor: Review 60-second dashboard -> edit/verify/approve.
- 4:00–5:00 Technology: Clinical ontology, deterministic rules, FHIR export.
