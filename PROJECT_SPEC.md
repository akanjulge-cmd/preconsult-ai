# PreConsult AI — Project Specification

## 1. Vision & Problem Statement
PreConsult AI is an accessible, assistive healthcare intake platform that bridges the communication gap between patients and clinicians. It provides a non-verbal, touch-first, visual semantic interaction pathway so non-speaking, speech-impaired, motor-impaired, elderly, or low-literacy patients can communicate accurate clinical complaints without typing or complex forms.

## 2. Core Principles
1. **Accessibility First:** No core task requires speech, typing, or fine-motor precision.
2. **Minimal Cognitive Load:** Maximum 4 taps for common clinical presentations; progressive disclosure.
3. **Adaptive Visual Semantics:** Translates intuitive visual animations (flames for burning, contracting bands for cramping, needles for sharp pain) into structured clinical data.
4. **Human-in-the-Loop:** Prepares the doctor, never diagnoses or replaces the doctor.
5. **Deterministic Safety:** Immediate red-flag detection halts routine intake when life-threatening symptoms are detected.
